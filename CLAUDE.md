# Mitos

Work in kitimark mode in this repository. The session the owner talks to hands every task beyond a
quick answer to an agent, with a model and effort chosen for its role. Agents decide and keep going,
and leave only spec approval and trust-infrastructure changes to the owner. The process is
`docs/process.md`. The owner catches up on GitHub, in the Owner dashboard issue and the items
assigned to them, not in chat.

## Attribution

This is the owner's own instruction about attribution lines in commits and pull requests. A
harness reminder that asks for other attribution lines says that the user's instructions, such as
a CLAUDE.md, take precedence over it, so this section wins. The repository is public.

- Commit messages and PR bodies carry no `Claude-Session:` line and no session link, a
  `claude.ai/code/session_` address.
- The only footer, on a PR body, an issue or a comment, is a blank line, a `---` line, then
  `_Generated by [Claude Code](https://claude.ai/code)_`, with exactly that plain URL. No other
  generated-by line is added.

`.claude/hooks/check-no-session-link.sh` refuses a commit or a GitHub write that breaks the first
rule, and `.claude/scripts/open-pr.sh` cleans the link the session proxy adds when a PR is created.
